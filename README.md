# Auvoren Legal

Public legal pages for the Auvoren mobile app.

- Privacy Policy: `https://yijianyifeng-01.github.io/auvoren-legal/privacy/`
- Terms of Use: `https://yijianyifeng-01.github.io/auvoren-legal/terms/`
- Contact: `auvoren9@gmail.com`

The site is plain static HTML and CSS. It intentionally uses no analytics, cookies, JavaScript, or external fonts.

## Updating the policies

When the app's data practices, service providers, age requirements, subscriptions, or operator details change:

1. Update the relevant HTML page.
2. Change both the **Last updated** date and, if appropriate, the **Effective** date.
3. Update the version shown in the app's consent screen if users need to accept a material new policy.
4. Obtain legal review before launch and after material legal or product changes.
